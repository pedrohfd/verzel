# Papel único por conta

Cada conta tem exatamente um papel: Cliente, Organizador ou Porteiro. Qualquer Cliente pode cadastrar um Cinema e virar Organizador, mas deixa de ser Cliente; para comprar Ingressos, o Organizador usa outra conta. O Porteiro é uma conta de serviço criada pelo Organizador, presa ao Cinema dele, e não pode cadastrar Cinema. Rejeitamos múltiplos papéis por conta para manter simples a autorização e a separação entre operar um Cinema e comprar nele.
